## 用户验收标准（已定，不要推翻）

以下来自用户对成稿的逐句反馈，是本项目最高约束，改动需用户确认：

1. **技能普通到废**：核心神迹必须是"问一句听懂了没有 / 把翻到的页讲出来"级别的日常动作。专业绝活不合格。
2. **全程大白话**：禁用"启发式提问""因材施教""层层递进"等术语——初稿因此被否决。
3. **震惊围绕废动作本身**：领导震惊的是"他居然会做这件事"，不是"做得好"。
4. **荒诞必须钻第二层**："他是不是还会等学生回答？""他是不是还会讲第39页？"——把废动作的最基本延伸当成更高神迹。
5. **不用正常智力写**：全世界降智到底，逻辑漏洞是笑点，不要修复。
6. **成文加标点断句**：源头是字幕体，但产出必须段落完整、带标点；保留"。。。"三连句号的 low 味。

## 写新案例的标准流程

1. 通读 `references/examples.md`
2. 填八槽位（职业 / 核心技能 / 最废仪式 / 引爆动作 / 围观者 / 直接领导 / 上级部门 / 抄袭对象）
3. 按五段公式成文
4. 对照六条铁律自查（重点：有没有术语？荒诞钻了几层？）
5. 加标点断句后直接给文，不解释套路
