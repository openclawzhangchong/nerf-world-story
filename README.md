# nerf-world-story 🎓⬇️

> 「一觉醒来，全国XX水平下降一万倍，而我保持不变」式**降智爽文梗**仿写技能。

让任何装了它的 AI 都能稳定产出这种梗文：全世界同行一夜降智一万倍、只剩最废的仪式动作，只有主角保持正常——主角随手干一件普通到不能再普通的小事，全场当神迹，领导层层发癫，结尾惊动上级："世界需要你这样的天才！"

## 效果示例（教师·翻书版）

> 把上课改成喊"把书翻到第38页"。。。一觉醒来，全国老师教学水平下降一万倍。而我却保持不变。此时我还没发现任何异常。
>
> 直到那天，我跟往常一样走进教室，本以为又是一节平平无奇的课堂，因为我只是一个刚开始工作的年轻教师。没想到我喊完"把书翻到第38页"，居然接着讲了这一页上写的是什么，全班学生立刻炸开了锅——听了这么多年课，第一次有老师把翻到的那一页讲出来。
>
> 教室的骚动很快引来了教导主任。听到我竟然会讲书上的内容，主任被震惊到目瞪口呆："这难道是传说中的翻书教学？这可是全国老师都不会的方法！一个小小的年轻教师，居然会把第38页讲出来。他是不是还会讲第39页？开什么玩笑啊。这种事，恐怕只有全国最厉害的老师进修1000年才能够想出来。他是怎么做到的？是抄袭名师的课吧。"
>
> 校领导决定把整节课录制下来。随着录像播放量的增加，各级教育部门终于注意到原本籍籍无名的我，兴冲冲地到学校找我："想不到我们县居然有你这样的一位天才，真是太好了！我们教育局有救了！世界需要你这样的天才！"

更多范例见 [references/examples.md](references/examples.md)。

## 安装

ZCode / Claude Code 等支持 `SKILL.md` 的 AI 工具，clone 即装：

```bash
# Linux / macOS
git clone https://github.com/openclawzhangchong/nerf-world-story.git ~/.agents/skills/nerf-world-story

# Windows (Git Bash)
git clone https://github.com/openclawzhangchong/nerf-world-story.git "C:/Users/<你>/.agents/skills/nerf-world-story"
```

其他 AI 框架：把整个文件夹放进对应技能目录即可——本仓库根目录就是一个标准技能包（`SKILL.md` + `references/`）。

## 用法

对装好技能的 AI 说：

- 「写一篇医生版」
- 「再来一篇理发师的」
- 「把XX职业套这个公式写一个」
- 「把上课改成喊'把书翻到第38页'，写一个」

技能即会按五段公式 + 写前铁律产出成文（含标点断句）。

## 写作铁律速览

1. **技能必须普通到废**——问一句"听懂了没有"，绝不能是专业绝活
2. **全程大白话，禁专业术语**——"启发式教学"这类词一律不准出现
3. **震惊围绕废动作本身**——震惊的不是"做得多好"，是"他居然会做"
4. **荒诞再钻一层**——"他是不是还会等学生回答？开什么玩笑啊！"
5. **不用正常智力写**——全世界降智到底，逻辑漏洞就是笑点
6. **成文加标点断句**——保留"。。。"的 low 味，但段落完整

完整规则见 [SKILL.md](SKILL.md)，公式拆解见 [docs/formula.md](docs/formula.md)，避坑经验见 [docs/lessons.md](docs/lessons.md)。
