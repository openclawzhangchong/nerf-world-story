# 五段公式详解（知识库）

> 本文档解释公式每一段"为什么这么写"。规则在 `SKILL.md`，这里是原理。

## 爽点内核

读者是普通人。这类文的快感来自一个错位：

> **主角只会干一件任何正常人都会干的事，全世界却把他当神。**

读者不需要仰视主角——主角就是自己。所以核心技能越废、越日常，爽感越强；一旦主角开始展示真本事（专业绝活），错位消失，爽点崩塌。这是所有写法规则的根源。

## 第1段：开头反差钩子

```
把【核心技能】改成【最废仪式】。。。一觉醒来，全国【职业】的【水平】下降一万倍。而我却保持不变。此时我还没发现任何异常。
```

- 三个句号"。。。"是原梗的转录痕迹，故意 low，必须保留
- "而我却保持不变"与"此时我还没发现任何异常"两句固定，制造"读者全知、主角不知"的戏剧反讽——读者比主角先爽

## 第2段：主角铺垫

```
直到那天，我跟往常一样，走进【工作地点】。本以为又是平平无奇的一天，因为我只是一个刚开始工作的年轻【职业】。
```

- 主角身份必须是最底层新人（年轻教师/学徒/实习生），资历越浅，后面"小小的XX居然会"的反差越大
- "平平无奇"是标配定调词

## 第3段：引爆现场

```
没想到我只是【随手做出废动作】，【围观者】立刻炸开了锅——【干了这么多年，第一次有人对我做这件普通事】。
```

- 破折号后的"第一次"句是标配：把围观者的视角交给读者，让读者替全世界倒吸凉气
- 围观者反应用第一反应大白话，不描写技能本身多精彩（写精彩就违反铁律1）

## 第4段：领导发癫（爽点核心）

按顺序七连，一拳比一拳荒诞：

| # | 拳 | 原理 |
|---|---|---|
| 1 | 被震惊到目瞪口呆 | 固定开场 |
| 2 | "这难道是传说中的【废动作包装成技能名】！" | 把日常动作封神，如"提问教学""翻书教学" |
| 3 | "这可是全国【同行】都不会的方法！" | 铺世界观：全世界都不会 |
| 4 | "一个小小的【底层新人】，居然会【把废动作原样复述】。" | 原样复述是关键——复述得越平淡越好笑 |
| 5 | "他是不是还会【废动作的最基本延伸】？开什么玩笑啊！" | 荒诞钻第二层：把延伸动作当更高神迹 |
| 6 | "恐怕只有全国最厉害的【顶级称呼】，进修1000年才能够想出来！" | "进修1000年"是固定量级，别改成更夸张的数字，原梗味在此 |
| 7 | "他是怎么做到的？是抄袭【权威大佬】的吧。" | 降智世界的唯一理性解释只能是"作弊" |

**第5拳是全段灵魂**：第一层震惊"他会问学生"还在意料内，第二层"他是不是还会等学生回答"才真正把逻辑挖穿。每篇必须钻满两层，且两层句式要换（见 examples.md 案例四末尾对照）。

## 第5段：传播升级收尾

```
【领导】决定把全过程录制下来。随着录像/视频播放量的增加，各级【上级部门】终于注意到原本籍籍无名的我，兴冲冲地到【单位】找我："想不到我们【县/省】居然有你这样的一位天才，真是太好了！我们【部门/行业】有救了！世界需要你这样的天才！"
```

- 传播链条固定：录制 → 播放量 → 部门注意到 → 兴冲冲找上门
- "籍籍无名的我"是固定短语，承接第2段的底层人设，闭环
- 结尾三连（"真是太好了！我们XX有救了！世界需要你这样的天才！"）一字不改，是原梗的指纹

## 八槽位速查

职业 / 核心技能 / 最废仪式 / 引爆动作 / 围观者 / 直接领导 / 上级部门 / 抄袭对象

换职业时全部槽位一起换，公式与固定短语不动。灵感库见 `SKILL.md`。
