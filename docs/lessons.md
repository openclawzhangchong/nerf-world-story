## 迭代史：一次关键的翻车与救回

### v0（翻车版）：专业腔

教师版初稿写了"听到我层层递进的启发式提问""这难道是传说中的因材施教""举一反三的课堂引导"。

用户反馈（原话大意）：**"你太专业词语了……总之，我告诉你，这就是要让一个普通人能看懂，屌丝看完都觉得带入很爽，但是技能是很普通的，所以你不要用正常智力去写。"**

问题诊断：
- "启发式提问""因材施教"是教育学黑话，普通读者无感 → 反差感消失
- "层层递进"是在夸技能水平 → 违反"技能必须废"的内核
- 用正常智力写 = 试图让降智世界讲逻辑 = 把笑点写没了

### v1（验收版）：大白话

改成：

> 听到我竟然会向学生提问，主任被震惊到目瞪口呆。这难道是传说中的提问教学！……一个小小的年轻教师，居然会问学生听懂了没有。他是不是还会等学生回答？开什么玩笑啊。

用户评价："非常好！我很满意！"该版入库为黄金标准（examples.md 案例三）。

## 事故与恢复实录（写给后来的维护者）

### 引号替换事故（2026-11-19）

批量把直引号统一为中文弯引号时，替换脚本经由 bash 双引号传参，`\\1` 被 shell 吃掉一个反斜杠，Python 收到八进制转义 `\1`（= U+0001 控制字符），导致 7 个批次文件里**所有引号内的内容被替换成不可见控制字符**——文件看起来只剩空引号 `“”`。

三条教训：
1. **带捕获组引用的正则替换永远不要经 bash 双引号传参**，写成脚本文件再跑（本项目最终用 `fix_quotes.py` + lambda 替换）。
2. **机检要在每次批量改文件后重跑**——这次机检恰好跑在替换之前，漏掉了事故。
3. **subagent 写盘的内容在 `~/.zcode/cli/artifacts/sess_subagent_agent_<id>/` 的 JSON artifact 里有完整副本**（`afterContent` 字段），文件被误改可从这里恢复，再重放人工修正。

恢复流程：找 artifact → 校验无控制字符 → 重放人工修正 → 重跑机检 → 抽查。

## 提炼出的可复用经验

1. **爽点是"废"，不是"强"。** 主角展示真本事的那一瞬间，屌丝代入感就断了。判断标准：把主角的技能讲给你爸妈听，如果他们觉得"这不是谁都会吗"，那就对了。
2. **领导台词的检验法**：逐句问"小学生能看懂吗"。任何成语、行业词、书面语都换成大白话。
3. **震惊要复述原动作。** "居然会问学生听懂了没有"——把废动作一字不差地放进领导的惊叹里，荒诞感来自"值得惊叹的事如此之小"。
4. **荒诞要钻两层，但句式要换。** 同一篇里"他是不是还会等学生回答"和"他是不是还会讲第39页"是同一个槽位，连载时必须换花样，否则读者看穿公式。
5. **保留转录 low 味，但成文要体面。** "。。。"三连句号、口语化的"开什么玩笑啊"保留；但错别字（原文"木灯口呆""幸冲冲""思出来"）在成文中修正，成文加标点断句。
6. **固定短语是原梗指纹，不许动**：进修1000年 / 籍籍无名的我 / 兴冲冲地 / 我们XX有救了 / 世界需要你这样的天才。
