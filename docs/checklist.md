# 检查要求（/test 规范）

> 任何新篇目入库前必须过两道关：**机检**（脚本，秒级）→ **人检**（逐篇人工，对照七问）。两关全过才算合格。

## 第一关：机检（先跑，不通过不入库）

```bash
python scripts/check.py                # 默认检查 stories/ 下全部 batch-*.md
python scripts/check.py <其他目录>     # 检查指定目录
```

退出码 0 = 通过。脚本逐篇检查以下内容（全部自动化）：

| 检查项 | 对应铁律 | 判定 |
|---|---|---|
| 固定短语 18 条逐一存在（进修1000年/籍籍无名的我/兴冲冲地/我们教育局有救了/世界需要你这样的天才……） | 公式指纹 | 缺一条即 FAIL |
| 第一段含"。。。"三连句号 | 铁律6 | FAIL |
| 全篇恰好 4 个自然段 | 五段公式 | FAIL |
| 篇号 1-100 连续、无缺、无重 | 合集完整性 | FAIL |
| 每文件恰好 10 篇 | 分批规范 | FAIL |
| 黑名单专业词（启发式/因材施教/循序渐进/层层递进/举一反三/核心素养/教学法……共 40+ 词） | 铁律2 | 出现即 FAIL |
| "是抄袭……吧"自我怀疑句存在 | 发癫七连第 7 拳 | FAIL |
| 中文引号配对 | 铁律6 | FAIL |
| 字数 250-700（目标 350-450） | 篇幅一致 | FAIL |
| "他是不是还会XXX"钻一层句式全局查重 | 防雷同 | 重复即 FAIL |
| "传说中的XXX"技能名全局查重 | 防雷同 | 重复即 FAIL |

## 第二关：人检（机检过了也要逐篇过，七问）

机检测不出"味道"。逐篇读，每篇回答七个问题，任何一个"否"就修：

1. **废不废？** 主角的"神迹"是不是一件读者自己也会干的日常小事？（把技能讲给你爸妈听，他们说"这不是谁都会吗"才对）
2. **白不白？** 领导的每一句台词，小学生能不能看懂？有没有漏网的书面语（黑名单之外的）？
3. **震惊对不对位？** 领导震惊的是"他居然会做这件事"本身，而不是"做得好/做得专业"？
4. **钻了几层？** 第一层震惊（他会做）+ 第二层震惊（他是不是还会延伸动作）都到位了吗？
5. **逻辑断没断？** 全世界降智到底了吗？有没有不小心把逻辑写顺、写得"合理"？（顺了 = 错）
6. **指纹全不全？** 固定短语、结尾三连是不是一字未改？"。。。"在不在开头？
7. **标点齐不齐？** 段落完整、引号配对、断句通顺，读起来是"加了标点的字幕体"而不是密不透风的大段？

## 修正流程

1. 跑 `python scripts/check.py`，列出全部 FAIL
2. 按篇号逐篇修正（改的是错，不改的是味道——固定短语永远不动）
3. 重跑脚本直到退出码 0
4. 人工按七问抽读 + 逐篇过，发现问题直接 Edit 修正
5. 全部通过后再 commit / 推送

## 新案例入库前的额外检查

- 与既有案例的"钻一层"句式不重复（脚本已查）
- 场景、围观者、引来的人不与最近 5 篇雷同（人工判断）
- 引爆点来自 docs/teacher-abilities.md 清单；清单外的新引爆点先补清单再写文


## 分镜文案检查（分镜提示词 / 15秒分镜）

两套分镜库共用这些检查（机检在 check_media.py，规则细节见 docs/storyboard-style.md）：

### 机检项（自动）
- 分镜提示词：每卷10条、每条3镜（约6/7/7秒）、全局人设块、主角简称、音画关键点、标志台词、违规词（画面区）
- 15秒分镜：每卷10篇、**单段总时长=15秒**（4+6+5）、时间轴行 0-4s/4-10s/10-15s、心声（画外）恰好3处、绝技OS结尾、领导加强词（冷汗直流/弯腰陪笑）、机位重复（平视平视）
- 篇号 1-100 连续无缺无重（三库各自独立校验）

### 人检项（人工）
1. 音画自洽：镜1画面=主角普通动作、台词=世界观反差；镜2=炸锅；镜3=收尾
2. 一切一个运镜，无"X转Y"双景别、无叠化/转场词
3. 动作 2-5 秒内做得完（低缓连续小动作，无微表情/手指特写）
4. frame 直呼角色名、shot 用通用身份——两套规矩不能混
5. 台词逐字（标志句一字不改），心声秒数 ≤ 镜头秒数
6. 时长核算行存在且总和 = 15
