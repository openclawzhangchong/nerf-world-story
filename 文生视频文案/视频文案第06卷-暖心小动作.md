# 视频文案第06卷｜暖心小动作（篇51-60）

> **用法说明**：每条 = 3 个镜头，按"镜头1约6秒 / 镜头2约7秒 / 镜头3约7秒"的节奏生成，三镜连播约 20 秒一条。每镜「画面提示词」整段直接复制粘进即梦"视频生成"，比例选 9:16；「台词字幕」用配音朗读或后期加字幕均可。镜头与镜头之间的转场不要写进提示词，在剪映 / 必剪里手动添加叠化即可。生成时传入主角正面定妆参考图（即梦"参考图 / 人物一致性"功能），可明显降低多条视频之间的变脸概率；提示词里可适当拉高"手部动作"类关键词权重，减少手部崩坏。
>
> **主角固定形象**（已统一写在每条开头的"全局统一人设"块，保证多条视频人物一致）：37岁中国男性教师，国字脸，黑色短发，身材挺拔，白衬衫深色西裤。
