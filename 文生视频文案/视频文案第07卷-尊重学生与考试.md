# 视频文案第07卷｜尊重学生与考试（篇61-70）

> **用法**：每条 = 3 个镜头，按「约6秒 / 约7秒 / 约7秒」节奏连成一条完整梗文视频（约20秒）。每镜「画面提示词」三行整段复制粘进即梦"视频生成"，比例选 9:16；台词字幕可直接配音，也可后期加字幕；镜头之间的转场在剪映/必剪中添加叠化即可。
>
> **人物一致性**：每条开头为全局统一人设，生成时请传入主角正面定妆参考图，降低变脸概率；涉及写字、发卷、数卷等手部动作的镜头，可拉高手部动作关键词的权重，减少手部崩坏。
>
> **本卷注意**：涉及试卷与分数的画面，提示词一律用"试卷上写着红色的分数""计数的笔画"等模糊表达，不写具体分数数字，避免生成乱字。
